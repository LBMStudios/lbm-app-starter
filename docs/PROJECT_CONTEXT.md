# Project context

This repository is the reusable baseline for LBM Studios web products. It is optimized for fast iteration without giving up reproducibility, security, or reviewability.

## Product constraints

- Spanish-first UI unless a project says otherwise.
- Responsive and accessible behavior is part of the acceptance criteria.
- Prefer simple platform capabilities over additional infrastructure.
- Each project forks or uses this template, then replaces this document with its own users, problem, scope, and metrics.

## Definition of done

The requested behavior works, lint/types/unit tests/build pass, important user paths have browser coverage, no secret is committed, and documentation reflects material changes.
